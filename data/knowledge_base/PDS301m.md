# Python for Applied Data Science _Lập trình Python cho khoa học dữ liệu ứng dụng

## 1. Thông tin chung
- **Mã môn học (Subject Code):** PDS301m
- **Tên tiếng Anh:** Python for Applied Data Science
- **Số tín chỉ (NoCredit):** 3
- **Môn tiên quyết (Pre-Requisite):** [[MAS291]]
- **Phương pháp dạy:** Inquiry-Based Learning,In-class lecture, Active Learning

## 2. Mô tả môn học (Description)
1. This hands-on course introduces students to Python programming with a specific focus on data science applications. Designed for beginners, it starts with the essentials of programming and guides learners through structured modules including Python basics, data structures, programming fundamentals, data handling, and APIs. Students will learn to write clean and efficient Python code, manipulate and analyze datasets, and automate data collection from external sources. Each topic is reinforced with review sessions and lab-based activities to ensure practical understanding and application. By the end of the course, students will be able to develop Python programs that solve real-world data problems and form a strong foundation for further study in data science and machine learning.

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Develop a foundational understanding of Python programming by learning basic syntax, data types, expressions, variables, and string operations.
- **CLO2:** Understand the key data structure in Python such as using data structures, conditions and branching, loops, functions, exception handling, objects, and classes.
- **CLO3:** Know how to apply proficiency in using Python libraries such as Pandas and Numpy and developing code using Jupyter Notebooks.
- **CLO4:** Understand and implement the way to access and extract web-based data by working with REST APIs using requests and performing web scraping
- **CLO5:** Apply AI tools to enhance Python programming skills and critically justify the logic of the implemented code
