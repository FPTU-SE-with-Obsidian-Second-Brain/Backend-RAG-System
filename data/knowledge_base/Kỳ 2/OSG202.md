# Operating System_Hệ điều hành

## 1. Thông tin chung
- **Mã môn học (Subject Code):** OSG202
- **Tên tiếng Anh:** Operating System
- **Số tín chỉ (NoCredit):** 3
- **Môn tiên quyết (Pre-Requisite):** N/A
- **Phương pháp dạy:** Social Constructivism,In-class lecture,Inquiry-based Teaching

## 2. Mô tả môn học (Description)
1. At the end of this course, students will be able to perceive:
2. 1) Background knowledge: (ABET e)
3. -The role of operating system,
4. - important OS concepts,
5. - the mechanism of operating system, and
6. - main problems of Operating system.
7. 2) Practice skills: (ABET k)
8. - Using basic shell command in Linux system fluently.
9. - Fundamental of shell, C language on Linux.
10. - Main problems of Operating system through some simulative exercises.
11. 3) Information searching, reading and selection skills (ABET i)
12. 4) Working in group, documenting and presenation skills (ABET g)

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Understand the main concepts of operating system
- **CLO2:** Understand the main concepts of process management
- **CLO3:** Understand the main concepts of memory management
- **CLO4:** Understand the main concepts of file systems
- **CLO5:** Understand the main concepts of I/O systems
- **CLO6:** Understand the main concepts of deadlock
- **CLO7:** Using Linux operating system
- **CLO8:** Using basic shell command in Linux system fluently
- **CLO9:** Understand basic Shell language on Linux
- **CLO10:** Understand basic C/C++ language on Linux
- **CLO11:** Using AI tools to futher explore the main concepts of OS's components
