# Microservices with Spring Cloud_Microservices với Spring Cloud

## 1. Thông tin chung
- **Mã môn học (Subject Code):** MSS301
- **Tên tiếng Anh:** Microservices with Spring Cloud
- **Số tín chỉ (NoCredit):** 3
- **Môn tiên quyết (Pre-Requisite):** [[SBA301]]
- **Phương pháp dạy:** Social Constructivism,In-class lecture,Inquiry-based Teaching

## 2. Mô tả môn học (Description)
1. Upon completion of this course students shoud:
2. Understand the followings:
• Microservices, Microservices architecture.
• The basics of Spring Cloud and its architecture
• The configuration and implementation using Spring Cloud
• The microservices architecture using Spring Cloud.
• The deployment of microservices-based applications using Docker and Spring Cloud tools
3. Be able to:
• Explain about Microservices architecture and its benefits, including scalability, resilience, and fault tolerance.
• Explain about Spring Cloud and its architecture
• Configure and implement Spring Cloud in a project
• Design and implement a microservices architecture using Spring Cloud
• Design, build, and deploy microservices-based applications using Docker and Spring Cloud tools
4. Be able to work in team and present group's results
