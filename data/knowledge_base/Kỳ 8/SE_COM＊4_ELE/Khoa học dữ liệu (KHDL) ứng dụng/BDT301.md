## 2. Mô tả môn học (Description)
1. This course introduces students to the principles and trade-offs in designing data-intensive systems, using Designing Data-Intensive Applications (2nd Edition) as the primary textbook.
2. Students will study:
3. Trade-offs in data systems architecture: OLTP vs OLAP, Cloud vs Self-Hosting, Distributed vs Single-Node systems.
4. Nonfunctional requirements: Scalability, Reliability, and Maintainability.
5. Data models: Relational, Document, and Graph-Like models.
6. Storage and retrieval: LSM-tree, B-Trees, columnar storage, Cloud Data Warehouses.
7. Batch processing: MapReduce and Apache Spark on large-scale public datasets.
8. Stream processing: Change Data Capture (CDC), Kafka/Redpanda, log-based messaging.
9. Data encoding: JSON, Protocol Buffers, Avro, schema evolution.
10. Distributed systems: Replication, Sharding, Transactions, and Isolation.
11. End-to-end data pipeline design from OLTP ingestion to OLAP analytical output.

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Analyze trade-offs and nonfunctional requirements of data systems, including OLTP versus OLAP, scalability, reliability, and maintainability.
- **CLO2:** Compare data models, storage engines, and encoding formats to select appropriate solutions for given workloads.
- **CLO3:** Explain replication, sharding, and transaction isolation in distributed data systems.
- **CLO4:** Apply batch processing techniques to analyze large datasets using Apache Spark and Spark SQL.
- **CLO5:** Build streaming data pipelines and design end-to-end systems from OLTP to OLAP.
