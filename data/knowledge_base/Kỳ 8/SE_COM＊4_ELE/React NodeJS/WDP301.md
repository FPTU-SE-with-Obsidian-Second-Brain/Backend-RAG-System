# Web Development Project_Dự án phát triển Web

## 1. Thông tin chung
- **Mã môn học (Subject Code):** WDP301
- **Tên tiếng Anh:** Web Development Project
- **Số tín chỉ (NoCredit):** 3
- **Môn tiên quyết (Pre-Requisite):** [[FER201m]], [[SDN301m]]
- **Phương pháp dạy:** Inquiry-based Teaching,Project Based Training,Offline

## 2. Mô tả môn học (Description)
1. 'This course focuses on designing, developing, and integrating the basic Web-based system/application using React, React Native, Node.js, Express technologies (with the system requirements, technical framework & NoSQL (MongoDB) as asigned/agreed by the teacher)
2. Students are required to build the system with other 3-5 team members as appointed by the teacher.
3. After the course, students will be able to achieve Fullstack web development proficiency with the following skills by practising with other members of the assigned team.
4. - Proficiency in common web techniques and React, Node.js, Express, React Native development skills
5. - Proficiency in front end skills (React, Bootstrap) require for industry
6. - Analyze & design the solution following the object oriented models
7. - Coordinate with the team to complete the works in the form of a project

## 3. Công cụ & Yêu cầu (Tools & Tasks)
### Yêu cầu với sinh viên:
- '- Build the team & select/define the project topic with arrangement/guide from the teacher
- Select the team leader and using the FPT account (@fpt.edu.vn account) to setup/configure the project managemernt environment (sources, tasks, issues, milestones) on the GitLab & project documents management on the OneDrive.
- Get the detailed assignment from the teacher, plan the project tasks, and execute the project accordingly
- Students must attend at least 80% of contact slots in order to be accepted to the final presentation.
- Student is responsible to do all exercises given by the teacher in class or at home and submit on time
- Constantly follow the teacher's guides/references for up-to-date course information regarding assignment submission and feedback on assignments and project work.
- Using the GitLab to collaborate in every phase of the project by all the team members

### Công cụ cần thiết:
- One Drive or Google Drive for document management
- GitLab (https://gitlab.com/) for issue and code version management
- Visual Studio Code (https://code.visualstudio.com)
- Internet
