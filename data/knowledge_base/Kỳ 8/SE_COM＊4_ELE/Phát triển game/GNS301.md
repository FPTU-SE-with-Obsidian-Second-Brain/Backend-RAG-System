## 2. Mô tả môn học (Description)
1. GNS301 is an intensive course designed to bridge the gap between game development and backend engineering. You will master the "hidden" infrastructure of online gaming—from raw data transmission and latency optimization to scalable server architectures. By the end of this course, you will be able to build secure, high-performance multiplayer environments capable of supporting real-time global interactions.
2. Key Learning Outcomes:
3. - Master Low-Level Networking: Build custom servers using TCP and Reliable UDP (LiteNetLib). Learn to handle raw sockets and binary serialization for maximum bandwidth efficiency.
4. - Combat Latency: Implement industry-standard lag-compensation techniques, including Client-side Prediction, Interpolation, and Server Reconciliation to ensure smooth gameplay.
5. - Architect Scalable Systems: Apply professional 3-Layer Architecture (Presentation, Logic, Data) to backend development. Integrate MongoDB for persistence and Docker for containerized deployment.
6. By the end of this course, you will have the skills to architect and develop a complete multiplayer ecosystem. You will possess the technical confidence to build not just a game, but a secure, scalable, and professional server infrastructure capable of delivering seamless real-time experiences to a global audience.

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Understand basic networking concepts (TCP/IP model, IP addressing, DNS) and game networking history.
- **CLO2:** Differentiate between common game network architectures (Client-Server, P2P, Dedicated Server) and their use cases.
- **CLO3:** Ability to implement data serialization using Binary and JSON formats to optimize network transmission.
- **CLO4:** Ability to build RESTful APIs using .NET Core and integrate MongoDB for player data storage.
- **CLO5:** Ability to program network communication systems using TCP and Reliable UDP via the LiteNetLib library.
- **CLO6:** Understand the principles of data synchronization (RPC, State Synchronization) and authority management.
- **CLO7:** Understand industry-standard lag compensation techniques (Client-side Prediction, Interpolation, and Server Reconciliation).
- **CLO8:** Understand the process of game server deployment using Docker and fundamental security measures.
