# Web Design_Thiết kế web

## 1. Thông tin chung
- **Mã môn học (Subject Code):** WED201c
- **Tên tiếng Anh:** Web Design
- **Số tín chỉ (NoCredit):** 3
- **Môn tiên quyết (Pre-Requisite):** None
- **Phương pháp dạy:** Online,Blended Learning

## 2. Mô tả môn học (Description)
1. Upon finishing the course, students can:
2. 1) Knowledge: Understand (ABET e)
3. - The concepts of HTML, CSS3, JavaScript, Interactivity with JavaScript, Advanced Styling with Responsive Design
4. - Web page structure.
5. - Web site structure.
6. - Demonstrate the ability to design and implement a responsive site for three platforms.
7. - The way a web page is presented in browsers.
8. 2) Able to (ABET k)
9. - Add interacitivity to web pages with Javascript
10. - Apply responsive design to enable page to be viewed by various devices
11. - Describe the basics of Cascading Style Sheets (CSS3)
12. - Use the Document Object Model (DOM) to modify pages
13. 3) Others: (ABET i)
14. - Improve study skills (academic reading, information searching, ...)

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Understand and demostrate how to get a site from the original version to HTML5
- **CLO2:** Use CSS3 to style a site dynamically
- **CLO3:** Add interacitivity to web pages with Javascript
- **CLO4:** Apply responsive design to enable page to be viewed by various devices
- **CLO5:** Apply all knowledge of skills learned in the courses to build a site
