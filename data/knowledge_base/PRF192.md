# Programming Fundamentals_Cơ sở lập trình

## 1. Thông tin chung
- **Mã môn học (Subject Code):** PRF192
- **Tên tiếng Anh:** Programming Fundamentals
- **Số tín chỉ (NoCredit):** 3
- **Môn tiên quyết (Pre-Requisite):** None
- **Phương pháp dạy:** Problem based learning, Active Learning

## 2. Mô tả môn học (Description)
1. Understand basics computer system and methods of software development, focus on function-oriented programming design, coding, testing and discipline in programming.
2. Explain basic concepts of programming, function-oriented programming design, modularity, understand and coding programs using C language.
3. Upon completing the course, student should have:
4. Knowledge: (ABET e)
- Explain the way to solve a real problem using computer.
- Understand the basic concepts computer system, and software development.
- Understand the basic concepts of programming, focus on procedure programming, testing and debugging, unit testing.
5. Skills in programming: (ABET k)
- Read and understand the simple C programs;
- Solve real problems using C.
6. Apply learning methods effectively: (ABET i)
- Academic reading.
- Individual and team work behaviors.

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Understand and describe about a program, and the way it works on computer.
- **CLO2:** Demonstrate about variables, expressions and basic operations and illustrate them by program examples.
- **CLO3:** Explain the meaning and use of Logic constructs in C Language. Describe about programming styles.
- **CLO4:** Describe about Modularity and Functions in C programs and their use.
- **CLO5:** Understanding and using pointers in programs.
- **CLO6:** Discuss about C Libraries and their use.
- **CLO7:** Discuss about Arrays, Struct and their use in C programs.
- **CLO8:** Discuss about Strings and their use in C programs.
- **CLO9:** Discuss about Files and their use in C programs.
