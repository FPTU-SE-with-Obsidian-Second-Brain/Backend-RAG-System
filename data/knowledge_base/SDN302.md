# Server-Side development with NodeJS, Express, and MongoDB_Phát triển Server-Side với NodeJS, Express và MongoDB

## 1. Thông tin chung
- **Mã môn học (Subject Code):** SDN302
- **Tên tiếng Anh:** Server-Side development with NodeJS, Express, and MongoDB
- **Số tín chỉ (NoCredit):** 3
- **Môn tiên quyết (Pre-Requisite):** [[DBI202]], [[FER202]]
- **Phương pháp dạy:** Lecture,Project based learning,Active learning,Social Constructivism, Discussion

## 2. Mô tả môn học (Description)
1. This course tackles all the problems related to NodeJS-based web servers. Contents to be implemented include:
2. - Overview of Web protocols: HTTP and HTTPS.
3. - Introduction of NodeJS and frameworks such as ExpressJS, NestJS, Hono to build a web server.
4. - Introduction of simple templating languages such as EJB and HandleBar .
5. - Deploy the application on a web server with basic CRUD operations. Work with NoSQL databases, specifically MongoDB and Mongoose, to access MongoDB from NodeJS.
6. - Overview of REST and building a RESTful API.
7. - Learn Authentication and security-related issues for web applications.
8. - Integrate React app with server NodeJs
9. - Deploy server-based applications with Hosting Services

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Understand Node, Node modules, API and the Node HTTP server
- **CLO2:** Understand Express, NestJS and Hono framework, operating principles, and methods of building a web server that supports REST API
- **CLO3:** Be able to use the Express Generator tool to generate Express applications
- **CLO4:** Understand MongoDB basics, develop Node applications that work with data through MongoDB and Mongoose ODM
- **CLO5:** Be able to implement REST APIs with Express, MongoDB, Mongoose and Mongoose Population
- **CLO6:** Be able to implement user authentication mechanisms for applications
- **CLO7:** Be able to use Backend as a Service (BaaS) to enhance secure communication between client and server applications
- **CLO8:** Be able to use EJB and HandleBar
