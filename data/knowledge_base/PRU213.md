# Game Programming with C#_Lập trình Game với C#

## 1. Thông tin chung
- **Mã môn học (Subject Code):** PRU213
- **Tên tiếng Anh:** Game Programming with C#
- **Số tín chỉ (NoCredit):** 3
- **Môn tiên quyết (Pre-Requisite):** [[PRO192]]
- **Phương pháp dạy:** Social Constructivism,In-class lecture,Inquiry-based Teaching

## 2. Mô tả môn học (Description)
1. This comprehensive Basic Unity Training Program is designed to equip participants with essential skills in Unity game development. Starting from the fundamentals of Unity interface and scripting in C#, the course progresses to cover advanced topics such as physics, animations, and user interface design. Through a combination of lectures, hands-on labs, and real-world projects, participants will gain practical experience and confidence in using Unity for game development.

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Understand the Unity interface and basic tools for game development
- **CLO2:** Write and implement C# scripts for game logic and interactions.
- **CLO3:** Create and manipulate game objects, animations, and physics components.
- **CLO4:** Design user interfaces and handle user input effectively.
- **CLO5:** Develop small games and interactive applications using Unity.
- **CLO6:** Troubleshoot and debug common Unity issues.
- **CLO7:** Collaborate effectively in a team environment for game development projects.
