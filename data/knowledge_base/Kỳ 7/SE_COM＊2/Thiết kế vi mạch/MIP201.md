## 2. Mô tả môn học (Description)
1. Hands-on Embedded Systems Development: Learn to implement real-world embedded system projects on microcontrollers (using both simulation environments and physical hardware) with the STM32Cube HAL library and STM32CubeIDE.
2. Peripheral Mastery & ARM Architecture: Master the core architecture of the ARM Cortex-M processor. Develop and refine C/C++ source code to build diverse applications (signal generators, temperature monitoring systems, audio players, and user interfaces) by leveraging Digital/Analog I/O, Interrupts, Timers, and Pulse-Width Modulation (PWM). Gain hands-on proficiency in analyzing and deploying serial communication protocols—SPI, UART, and I2C—while evaluating their advantages and limitations in embedded environments.
3. Real-Time Operating Systems (RTOS): Explore the core characteristics of RTOS and multitasking mechanisms on microcontrollers. Students will directly apply Threads, Mutexes, Semaphores, and Interrupts to design a complete multitasking system, effectively resolving resource contention issues.
4. Practical Engineering Skills: Prototype embedded systems using the ST Nucleo-F401RE (ST Nucleo-F411RE) development board and cost-effective components. Enhance hardware-level C/C++ programming mindsets by immediately applying theory to practice. Master the end-to-end hardware development workflow alongside professional debugging and troubleshooting techniques.

### Công cụ cần thiết:
- Specific Tools:
- Hardware & Training Kits
- Development Board: ST Nucleo-F401RE (powered by the ARM Cortex-M4 core).
- Programmer & Debugger: On-board ST-Link/V2 debugger, supporting the SWD (Serial Wire Debug) protocol.
- Software Development Environment
- Primary IDE: STM32CubeIDE (fully replaces Keil Studio Cloud and Mbed Studio). This is the industry-standard IDE for C/C++ development on ST microcontrollers.
- Simulation Software: Wokwi (a free, web-based open-source simulator supporting STM32 boards and various peripherals) or other debugging/simulation tools recommended by the instructor.

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Understand the fundamentals of an embedded system and discover the ARM architecture and microcontrollers.
- **CLO2:** Understand the characteristics of microcontrollers and embedded systems, including their components, benefits, and constraints.
- **CLO3:** Understand the industry-standard ARM-based microcontroller architecture, its features, and programming models.
- **CLO4:** Develop working embedded prototypes using the STM32 HAL library, FreeRTOS, the ST Nucleo-F401RE board (or ST Nucleo-F411RE board), and low-cost peripherals.
- **CLO5:** Apply knowledge of digital and analog I/O programming on STM32 microcontrollers.
- **CLO6:** Implement interrupts to control peripherals using the STM32 HAL library.
- **CLO7:** Develop applications incorporating timers and Pulse Width Modulation (PWM) using the STM32 HAL library.
- **CLO8:** Evaluate serial communication protocols used in embedded systems (UART, SPI, and I2C), including their benefits and limitations.
- **CLO9:** Understand Real-Time Operating Systems (FreeRTOS) and how they facilitate multitasking in embedded systems.
- **CLO10:** Implement real-world embedded system projects on the STM32 Nucleo board using FreeRTOS, with proper task synchronization (Mutex/Semaphore).
