## 2. Mô tả môn học (Description)
1. This advanced Unity course builds on foundational skills to empower you with expert-level knowledge in creating professional, high-performance games. You'll dive deep into SOLID principles and design patterns for writing clean, scalable code, while mastering Unity's networking tools and cloud services to build engaging multiplayer experiences. Hands-on projects will help you optimize performance, integrate AI, and deliver polished games ready for consoles, PC, and beyond.
2. Key Learning Outcomes:
3. - Master SOLID Principles: Build a solid grasp of the five SOLID principles (Single Responsibility, Open-Closed, Liskov Substitution, Interface Segregation, and Dependency Inversion) and apply them to make your Unity code more modular and easier to maintain.
4. - Implement Design Patterns: Get hands-on with essential Unity patterns like Singleton, Observer, Command, Strategy, Factory, Decorator, and State to organize code, boost flexibility, and simplify complex game logic.
5. - Build with Unity Networking: Explore Unity Relay and Netcode to design smooth, reliable multiplayer systems that handle real-time interactions effortlessly.
6. - Integrate Unity Gaming Services: Use cloud tools like Player Authentication, Lobbies, In-Game Economy, and Leaderboards to add secure, scalable features that enhance player engagement.
7. - Optimize Performance: Discover profiling techniques and best practices to fine-tune your games for buttery-smooth gameplay, reduced lag, and efficient resource use on various devices.
8. - Create Multiplayer Games: Develop small real-time multiplayer prototypes using Unity's networking and collaboration tools, following industry-standard workflows.
9. - Leverage Unity AI: Incorporate AI models via Unity Sentis or similar tools to add intelligent behaviors, like smart NPCs or procedural content, to your game projects.
10. By the end of this course, you'll have the confidence and skills to solve tough game development problems, from code architecture to live multiplayer features, and produce professional-quality games with cutting-edge design and tech.
