# Integrate single page application with Spring Boot_Tích hợp ứng dụng trang đơn với Spring Boot

## 1. Thông tin chung
- **Mã môn học (Subject Code):** SBA301
- **Tên tiếng Anh:** Integrate single page application with Spring Boot
- **Số tín chỉ (NoCredit):** 6
- **Môn tiên quyết (Pre-Requisite):** [[HSF302]]
- **Phương pháp dạy:** Project based learning,Problem based learning,Active learning,In-class lecture

## 2. Mô tả môn học (Description)
1. Upon completion of this course students shoud:
2. Understand the followings:
• ReactJS concepts for building Front-End application
• RESTful API concepts
• RESTful API using Spring Boot's built-in features and frameworks
• Security features (authentication and authorization) with RESTful API
• Handling HTTP requests and responses using Spring Boot's framework
• Error handling and exception management in Spring Boot RESTful APIs
3. Be able to:
• Build RESTful APIs using Spring Boot's built-in features and frameworks
• Implement security features with authentication and authorization
• Handle HTTP requests and responses using Spring Boot's framework
• Build Front-End application using ReactJS components
• Integrate Spring Boot with other technologies and frameworks SQL Server, MongoDB, and ReactJS
4. Be able to work in team and present group's results

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Understand of the ReactJS library, services, and dependency injection.
- **CLO2:** Apply fetch and catching data in Client-Server Communication
- **CLO3:** Describe RESTful APIs using Spring Boot's built-in features and frameworks
- **CLO4:** Describe the connecting RESTful Web Service with JPA
- **CLO5:** Apply security features such as authentication and authorization
- **CLO6:** Create application with Hibernate and Spring Framework.
- **CLO7:** Apply Spring Data with MongoDB to build an application.
- **CLO8:** Develop teamwork skills, communication skills (including presentation skills)
