## 2. Mô tả môn học (Description)
1. This course introduces the core concepts and practical techniques of machine learning for data science through practical, hands-on work with Python.
2. Students will learn how to preprocess and analyze data, implement common machine learning algorithms, and evaluate model performance using appropriate metrics.
3. Using modern tools such as Scikit-Learn and PyTorch, student will practice solving real data problems including prediction, classification, clustering and basic deep learning.
4. Additionally, students will gain basic experience deploying trained models through simple APIs and interpreting predictions with attention to ethical considerations.

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Understand Core Concepts: Explain fundamental machine learning principles of machine learning, distinguish between supervised, unsupervised, and reinforcement learning, and describe the end-to-end ML workflow.
- **CLO2:** Prepare and Analyze Data: Proficiently preprocess datasets, perform exploratory data analysis, and engineer relevant features to support effective model training.
- **CLO3:** Implement and Train Models: Implement and train a variety of key machine learning algorithms - including linear models, tree-based ensembles, and clustering methods - using standard Python machine learning libraries.
- **CLO4:** Evaluate and Validate Models: Select and use appropriate metrics to evaluate model performance, diagnose issues such as overfitting or underfitting, and validate model performance using techniques like cross-validation.
- **CLO5:** Apply Neural Networks: Understand the fundamentals of neural networks and build/train deep learning model using modern frameworks such as PyTorch for tasks including image classification.
- **CLO6:** Deploy and Interpret Models: Demonstrate basic model deployment by exposing a trained model through a simple API and interpret model predictions while recognizing ethical and data bias considerations.
- **CLO7:** Integrate ML solution into software system: Design, implement, and integrate a complete ML solution into a software system, including proper documentation, testing, and API deployment following software engineering best practices.
