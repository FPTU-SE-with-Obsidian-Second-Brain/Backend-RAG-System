# Data Handling and Visualization_Xử lý và Trực quan hóa Dữ liệu

## 1. Thông tin chung
- **Mã môn học (Subject Code):** DHV301
- **Tên tiếng Anh:** Data Handling & Visualization
- **Số tín chỉ (NoCredit):** 3
- **Môn tiên quyết (Pre-Requisite):** [[PDS301m]]
- **Phương pháp dạy:** Inquiry-Based Learning, In-class lecture, Active Learning

## 2. Mô tả môn học (Description)
1. Upon completion of this course students should:
2. Understand the followings:
• Data acquisition, data quality, and the end-to-end data handling pipeline
• Data wrangling concepts: missing values, data types, normalization, encoding
• Exploratory data analysis (EDA) and statistical reasoning (correlation, ANOVA, chi-square)
• Visualization principles and data storytelling for different audiences
• Dashboarding concepts and Power BI semantic modeling (star schema, relationships, measures)
3. Be able to:
• Load data from CSV/Excel/JSON/SQL into Python (Pandas) and export results for reuse
• Clean and transform data in Python and Excel/Power Query to prepare analytical datasets
• Build effective charts with Matplotlib/Seaborn/Folium and communicate insights
• Develop interactive Power BI reports/dashboards and publish to Power BI Service
• Apply a simple predictive model (regression) to support data-driven decision making
4. Be able to work in team and present results with reproducible notebooks and dashboards

## 4. Tài liệu học tập (Materials)
- **Tài liệu chính:** Python for Data Analysis: Data Wrangling with pandas, NumPy, and Jupyter (Wes McKinney, O’Reilly Media, 2022).
- **Tham khảo:** Fundamentals of Data Visualization: A Primer on Making Informative and Compelling Figures (Claus O. Wilke, O’Reilly Media, 2019).
- **Tham khảo:** Microsoft Power BI Cookbook: Convert raw data into business insights with updated techniques, use cases, and best practices (Greg Deckler, Brett Powell, Packt, 2023).
- **Tham khảo:** pandas User Guide: IO tools (pandas developers, pandas.pydata.org).
- **Tham khảo:** Matplotlib Pyplot tutorial (Matplotlib developers, matplotlib.org).
- **Tham khảo:** Power BI documentation (Microsoft, learn.microsoft.com).
- **Tham khảo:** Power BI guidance: Star schema (Microsoft, learn.microsoft.com).

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Apply data handling techniques (import, clean, transform, summarize) to prepare datasets for analysis in Python/Excel/Power Query.
- **CLO2:** Communicate insights using data storytelling: select audience-appropriate narratives, annotate visuals, and write concise interpretations.
- **CLO3:** Create clear and accurate visualizations in Python (Matplotlib/Seaborn/Folium), choosing suitable chart types and design best practices.
- **CLO4:** Build interactive dashboards in Power BI using good data modeling (relationships/star schema) and DAX measures, then publish and share responsibly.
