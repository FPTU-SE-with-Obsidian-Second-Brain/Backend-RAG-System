## 2. Mô tả môn học (Description)
1. SWE201c is for people who are new to software engineering. It's also for those who have already developed software, but wish to gain a deeper understanding of the underlying context and theory of software development practices.
2. At the end of this course, we expect learners to be able to:
3. ) Build high-quality and secure software using SDLC methodologies such as agile, lean, and traditional/waterfall.
4. ) Analyze a software development team's SDLC methodology and make recommendations for improvements.
5. ) Compare and contrast software development methodologies with respect to environmental, organizational, and product constraints.

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Compare and contrast software development methodologies with respect to environmental, organizational, and product constraints.
- **CLO2:** Demonstrate the ability to participate effectively in agile practices/process for software development.
- **CLO3:** Apply lean techniques / methods to software development
