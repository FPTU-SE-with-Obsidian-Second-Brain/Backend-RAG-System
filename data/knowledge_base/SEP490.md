## 2. Mô tả môn học (Description)
1. The capstone project provides students important skills and initial experiences in participating in the software projects. Student can apply knowledges they have learned to the real current projects include:
2. - Experiencing across all project phases: requirement, design, coding, testing and release
3. - Finding out and using the templates and composing documents for each project stage
4. - Using knowledges of technology that have been taught
5. - Having the opportunity to research and apply new technologies
6. - Practicing teamwork and how to interact with colleagues in a project implementation process
7. - Ensuring the proper implementation of quality requirements and schedule
8. - Doing troubleshooting
9. With the team size of 4-5 members, the output product size are required to be equivalent to 20-25 medium use cases (3-7 transactions for each use case; action buttons on the screen, end user interactions to the software screens/functions or database transactions can be counted as transaction)
10. The capstone project provides students, working in groups, with a significant project experience in which they can integrate much of the material they have learned in their program, including matters relating to requirements, design, implementation, human factors, professionalism, and project management. Students should be expected to deliver one or several iterations of a software system, along with all artifacts appropriate to the process model they are using. These would likely include
11. a) Project management Plan (perhaps updated regularly),
12. b) Software Requirements Specifications (SRS)
13. c) Software Design Documents (SDD)
14. d) Test Plan and other Test Documentation (STD)
15. e) Software package & the user guides (package content, installation guide & user manuals)
16. All the documents in the project implementation process and the progress reports are required to write in English.

## 3. Công cụ & Yêu cầu (Tools & Tasks)
### Yêu cầu với sinh viên:
- # Choose appropriate project and form group.
- # Divide and schedule work among members.
- # Attend all scheduled meeting with supervisor.
- # Produce document and product according to project requirement and member work share.
- # Defend work infront of examination board, showing both project results and individual responsibility.
- # In case of cheating found, the whole team is not allow to defend.
- #Students are required to attend at least 80% of scheduled meetings with their supervisor(s) to be eligible for the thesis or capstone defense.

### Công cụ cần thiết:
- Appropriate tools for design and implementation.

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Use the knowledge of contemporary issues to identify a problem requiring technology intervention and specify the requiments for the proposed solution.
- **CLO2:** Design a software solution, with consideration of techical & others factors.
- **CLO3:** Implement the design, including testing verification.
- **CLO4:** Apply project management principles to software development project.
- **CLO5:** Write a professional research report.
- **CLO6:** Practice oral presentation and inter-personal communications.
- **CLO7:** Exhibit professional working attitudes
