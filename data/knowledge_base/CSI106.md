- **Tên tiếng Anh:** Introduction to Computer Science
- **Số tín chỉ (NoCredit):** 3

## 2. Mô tả môn học (Description)
1. This course provides an overview of computer fundamentals. Topics cover all areas of computer science in breadth such as computer organization, network, operating system, data structure , file structure, social and ethical issues.
2. Major Instructional Areas
3. - Introduction to Von Neumann Model and computer components
4. - Numbering system & data representation
5. - Different data types and operations on data
6. - The concepts of computer networking and internet
7. - Operating system
8. - Introduction to basic algorithms and algorithms representation
9. - Introduction to Data structure and File structure
10. - The concepts of database
11. - Software engineering
12. - Computing Security & Ethics
13. - Introduction to Artificial Intelligence (Additional Learning)

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Understand the subsystems of a computer and describe the role of these components
- **CLO2:** Know how to convert a number from one base to other base( decimal, binary, octal and hexadecimal)
- **CLO3:** Describe how different data type is stored inside a computer as bit patterns and operations on data
- **CLO4:** Describe the layers in netwoking and their relationship
- **CLO5:** Undestand the role of OS in a computer system
- **CLO6:** Define a algorithm and describe tools used to develop algorithms
- **CLO7:** Explain how a program in a high-level language is translated into machine language
- **CLO8:** Describe the software lifecycle
- **CLO9:** Discuss some data structures: Array, Records, Linked list
- **CLO10:** Distinguish between text file and binary file and access methods
- **CLO11:** Describe and explain operations within a relational database
- **CLO12:** Descibe security goals and discuss ethical issues
- **CLO13:** Describe artificial intelligence and its basic concepts
