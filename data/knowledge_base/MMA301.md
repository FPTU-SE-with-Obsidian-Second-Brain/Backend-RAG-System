# Multiplatform Mobile App Development_Phát triển ứng dụng di động đa nền tảng

## 1. Thông tin chung
- **Mã môn học (Subject Code):** MMA301
- **Tên tiếng Anh:** Multiplatform Mobile App Development
- **Số tín chỉ (NoCredit):** 3
- **Môn tiên quyết (Pre-Requisite):** [[FER202]]
- **Phương pháp dạy:** Problem based learning, Active Learning

## 2. Mô tả môn học (Description)
1. This course helps learners master the knowledge of React Native. Learners can quickly develop mobile applications running on iOS and Android platforms. Contents to be implemented include:
2. - Overview of React Native and its benefits.
3. - Setting up the development environment.
4. - Understanding components and navigation.
5. - Hands-on experience with iOS simulator and Android emulators
6. - Techniques for styling applications.
7. - State management strategies using hooks and Redux.
8. - Managing user input and touch events.
9. - Using FlatList and SectionList for data presentation.
10. - Mobile Notifications: Learn to integrate personalized notifications to enhance user engagement.
11. - Databases: Explore using SQLite, Firebase for data management.
12. - Debugging techniques and tools.
13. - Publishing applications using Expo.
14. - Integrate mobile app with Gemini AI

## 6. Lộ trình chi tiết (Sessions)
- **Session 1:** Course Introduction (CLO1). Nhiệm vụ: Listen actively, understand course structure, objectives, grading, and expectations. Ask clarifying questions.. Tài liệu: [MMA301](https://flm.fpt.edu.vn/download/12848/S/1_MMA301.zip)
- **Session 2:** Introduction to React Native
- What is React Native
- Features and Use Cases of React Native
- React Native architecture (CLO1, CLO2). Nhiệm vụ: Understand core concepts, features, pros/cons of React Native. Take notes. Ask questions.
- **Session 3:** Setting up the React Native Development Ecosystem
- Common Dependencies
- Node.js Installation
- Android Studio Setup
- Android SDK Configuration
- Environment Variables: Set up the ANDROID_HOME environment (CLO3). Nhiệm vụ: Follow instructions to install Node.js, Watchman, IDE extensions, Expo CLI dependencies. Troubleshoot setup issues with guidance.
- **Session 4:** Setting up the React Native Development Ecosystem (Cont)
- Expo and Its Features
- Install Expo Go on your device
- Expo CLI
- Setting up the Environment using Expo Snack (CLO3). Nhiệm vụ: Complete Expo setup. Create a new project using Expo CLI. Run the basic app on a device or simulator.
- **Session 5:** Emulator and Simulator Basics in React Native Development
- Understanding Android SDK Emulator - Android SDK Emulator
- Working with Android Emulator using Android Studio
- iOS Simulator
- Configuring iOS Simulator (CLO3). Nhiệm vụ: Set up and configure an Android Emulator (AVD) and/or iOS Simulator. Practice running their app on these virtual devices.
- **Session 6:** - Navigating the project structure in React Native using Expo commands
- Compare Expo CLI versus React Native CLI (CLO2, CLO3). Nhiệm vụ: Explore the folders and files in a standard Expo/React Native project. Understand the purpose of key files (App.js, package.json, assets, etc.).
- **Session 7:** Introduction to Virtual DOM in React Native (CLO1, CLO2). Nhiệm vụ: Understand the concept of the Virtual DOM and how it contributes to React Native's performance. Compare briefly with the web DOM.
- **Session 8:** Introduction to Basic Components
- View
- Text
- Image
- Button
- Text Input
- Scroll View
- Flat List (CLO4). Nhiệm vụ: Learn the syntax and basic props for View, Text, Image, Button, TextInput. Practice using these components to build a simple static screen layout.
- **Session 9:** Introduction to React Navigation Components
Implementation of Stack, Drawer, and Tab Navigation (CLO4). Nhiệm vụ: Implement basic stack navigation between two or more screens using react-navigation. Understand navigator setup.
- **Session 10:** Introduction to Stylesheets (CLO5). Nhiệm vụ: Learn how to create and apply styles using StyleSheet.create
Practice styling basic components (color, font size, margins, padding)
- **Session 11:** Styling with Layouts and Flexbox (CLO5). Nhiệm vụ: Practice using Flexbox properties (flexDirection, justifyContent, alignItems, flex, etc.) to create responsive layouts. Complete layout exercises.
- **Session 12:** Using Styled-Components in React Native (CLO5). Nhiệm vụ: Understand the concept of CSS-in-JS with Styled Components. Practice defining and using styled components. (Optional: Refactor previous styles).
- **Session 13:** Managing State with useState and useReducer (CLO6). Nhiệm vụ: Practice using useState for simple state variables and useReducer for more complex state logic within components. Implement examples like counters or simple forms.
- **Session 14:** Using Context API for State Management (CLO6). Nhiệm vụ: Implement state sharing between components using the Context API. Understand createContext, Provider, and useContext.
- **Session 15:** Redux in React Native (CLO6). Nhiệm vụ: Understand the core Redux concepts (actions, reducers, store, dispatch). Practice connecting a component to the Redux store (if guided).
- **Session 16:** Handling TextInput and Forms (CLO4). Nhiệm vụ: Build a form with TextInput fields. Implement controlled components by managing input state using useState. Handle form submission.
- **Session 17:** Validating Forms with Formik and Yup (CLO4). Nhiệm vụ: Integrate Formik to manage form state and Yup for validation rules in their practice form. Display validation errors.
- **Session 18:** Using AsyncStorage for Persistent Data (CLO9). Nhiệm vụ: Practice saving simple data (e.g., user preferences, a token) to AsyncStorage and retrieving it when the app restarts.
- **Session 19:** Introduction to FlatList and SectionList (CLO7). Nhiệm vụ: Practice rendering large lists of data efficiently using FlatList. Understand data, renderItem, keyExtractor. Implement a SectionList for grouped data.
- **Session 20:** Implementing Pull-to-Refresh (CLO7). Nhiệm vụ: Add pull-to-refresh functionality to a FlatList or ScrollView using RefreshControl. Trigger a data refresh action.
- **Session 21:** Implement Infinite Scrolling (CLO7). Nhiệm vụ: Implement infinite scrolling (load more data on reaching the end) on a FlatList using onEndReached prop.
- **Session 22:** Assignment 1 (CLO1, CLO2, CLO3, CLO4, CLO5, CLO6, CLO7, CLO9). Nhiệm vụ: Work actively on Assignment 1, applying concepts from sessions 1-21. Ask specific questions for clarification or help.
- **Session 23:** Assignment 1 (CLO1, CLO2, CLO3, CLO4, CLO5, CLO6, CLO7, CLO9). Nhiệm vụ: Continue working on Assignment 1. Focus on problem-solving and implementation. Collaborate if permitted.
- **Session 24:** Assignment 1 Review
Project Introduction (CLO1, CLO2, CLO3, CLO4, CLO5, CLO6, CLO7, CLO9). Nhiệm vụ: Submit Assignment 1. Pay attention to the review, noting common mistakes or best practices. Understand the final project scope and start brainstorming. Ask questions about the project.
- **Session 25:** Progress Test 1 (CLO1, CLO2, CLO3, CLO4, CLO5, CLO6, CLO7, CLO9). Nhiệm vụ: Take the test
- **Session 26:** Working with React DevTools
- Inspecting Components
- Using Context API (CLO8). Nhiệm vụ: Practice using React DevTools to inspect component hierarchy, view/edit props and state in their own or example apps.
- **Session 27:** Working with React DevTools  (Cont)
- Performance Profiling (CLO8). Nhiệm vụ: Practice using the Profiler tab in React DevTools to identify rendering bottlenecks in simple scenarios.
- **Session 28:** Handling Errors and Debugging
- Importance of Error Handling
- Common Error Types
- Error Handling Techniques: (CLO8). Nhiệm vụ: Learn common types of errors. Practice using console logs and the debugger (Chrome DevTools) for basic debugging. Understand Error Boundaries concept.
- **Session 29:** Handling Errors and Debugging  (Cont)
- Debugging Tools (CLO8). Nhiệm vụ: Practice setting breakpoints, inspecting variables, and stepping through code using the debugger.
- **Session 30:** Creating Android APK Files
Handling Updates in React Native (CLO3, CLO13). Nhiệm vụ: Understand the process for creating a release build (APK/AAB). Learn the concept of Over-the-Air (OTA) updates.
- **Session 31:** Mobile App Notifications, Databases, & Publishing Introduction (CLO11, CLO12, CLO13). Nhiệm vụ: Gain a high-level understanding of push notifications, local vs. remote databases, and the app store submission process.
- **Session 32:** Handling Notifications in Mobile Apps
Notification Delivery Systems (CLO11, CLO12). Nhiệm vụ: Understand the flow of push notifications (client registration, server sending, client receiving). Learn about permissions.
- **Session 33:** Creating Notifications in React Native (CLO12). Nhiệm vụ: Practice setting up a library (e.g., expo-notifications) to request permissions and potentially receive local or test push notifications.
- **Session 34:** Embedded databases introduction
- Local Storage
- SQLite
- Couchbase Lite
- LevelDB
- BerkeleyDB
Best Practices for Developers (CLO9, CLO11). Nhiệm vụ: Understand use cases for local databases. Learn basic SQL concepts relevant to SQLite. Practice setting up expo-sqlite.
- **Session 35:** CRUD Operations in Embedded Databases
- Operations (CLO9). Nhiệm vụ: Practice writing and executing SQL queries for Create, Read, Update, and Delete operations in SQLite
- **Session 36:** CRUD Operations in Embedded Databases ( cont )
- Practical Application (CLO9). Nhiệm vụ: Apply CRUD operations to a practical example within their app (e.g., saving notes, user data locally). Handle asynchronous database operations.
- **Session 37:** Overview of Remote Databases (CLO9, CLO11). Nhiệm vụ: Understand the difference between local and remote databases. Learn about common remote database types (SQL, NoSQL) and BaaS options.
- **Session 38:** Connecting Mobile Apps to Remote Databases (CLO9, CLO11). Nhiệm vụ: Practice making API calls to retrieve data from a sample public API or a simple backend provided by the lecturer. Handle responses and errors.
- **Session 39:** Introduction to Firebase (CLO11). Nhiệm vụ: Create a Firebase project. Understand the key services offered (Firestore/Realtime DB, Auth, etc.). Connect their React Native app to the Firebase project.
- **Session 40:** Explore Google Firebase (CLO11). Nhiệm vụ: Explore the Firebase console. Practice basic data operations (adding/reading data) in Firestore or Realtime Database directly or through guided app integration.
- **Session 41:** Creating Notifications in React Native with Firebase (CLO11, CLO12). Nhiệm vụ: Integrate Firebase Cloud Messaging (FCM) setup into their app. Practice receiving notifications sent via the Firebase console.
- **Session 42:** Gemini AI integration
- Get API key
- Project configuration (CLO10). Nhiệm vụ: Obtain a Gemini API key. Set up the necessary SDK/API call structure in their project. Configure the project securely.
- **Session 43:** Gemini AI integration (cont)
- AI Model selection
- Make promt and processing result (CLO10). Nhiệm vụ: Practice selecting an appropriate Gemini model. Formulate prompts and make API calls from the app. Display the AI-generated response.
- **Session 44:** Map integration
- Request permission

- **Session 45:** Image picker integration (CLO4). Nhiệm vụ: Install expo-image-picker. Implement functionality to request permissions, open the device's image gallery or camera, and handle the selected image URI.
