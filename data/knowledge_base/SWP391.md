# Software development project_Dự án phát triển phần mềm

## 1. Thông tin chung
- **Mã môn học (Subject Code):** SWP391
- **Tên tiếng Anh:** Software Development Project
- **Số tín chỉ (NoCredit):** 3
- **Môn tiên quyết (Pre-Requisite):** [[PRJ301]], [[SWE201c or SWE202c]], [[pass LAB211]]
- **Phương pháp dạy:** Lecture, Lab, Group Discussion, Presentation, Peer Review.AI-integrated tasks across all Software Development Life Cycle phases

## 2. Mô tả môn học (Description)
1. This course guides students through the full Software Development Life Cycle (SDLC) by working on a real-world team project, with an emphasis on applying AI responsibly in requirement analysis, design, implementation, and testing. Students will practice user story writing, system design, coding using MVC and OOP, workflow development, testing, and reporting. AI tools are integrated into each phase to enhance productivity and quality.

## 3. Công cụ & Yêu cầu (Tools & Tasks)
### Yêu cầu với sinh viên:
- Join the team as arranged by the teacher
- Select the project topic & technology stack and get approval from teacher before implementing
- Attend at least 80% of contact slots in order to be accepted to the final presentation.
- Analyze requirements, write user requirements, and create system diagrams with AI-assisted tools.
- Design system architecture, database schema, and UI/UX wireframes using MVC, OOP, and AI suggestions.
- Implement core features with AI-supported coding, apply coding standards, and manage source code in Git.
- Develop and run unit/integration tests, using AI to suggest and refine test cases.
- Deploy the application to staging, verify functionality, and prepare for final delivery.
- Manage project progress, present milestones, and prepare high-quality reports with AI support.

### Công cụ cần thiết:
- Requirement & Design: Miro, Lucidchart, Figma, Draw.io, ChatGPT, Gemini
- Coding & Debugging: IntelliJ IDEA / VS Code / Visual Studio, GitHub Copilot, Tabnine
- Database: MySQL Workbench, SQL Server Management Studio, pgAdmin
- Testing: JUnit, NUnit, Postman, Selenium, AI-powered test case generators
- Project Management: Jira, Trello, Notion, Git/GitHub
- Deployment: Docker, Heroku, AWS / Azure / GCP, Vercel

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Analyze and clarify project requirements with AI-assisted elicitation and documentation
- **CLO2:** Design system modules and databases using MVC, OOP, and AI-supported modelling tools
- **CLO3:** Create ERD models and implement relational databases with SQL, applying AI tools for design validation and query optimization.
- **CLO4:** Develop web applications in Java/.NET/Node.js with AI-enhanced coding, debugging, and workflow implementation.
- **CLO5:** Demonstrate teamwork, professional ethics, and responsible AI use in software development.
- **CLO6:** Deliver effective presentations and reports with AI-aided content and visualization.
