# Building Cross-Platform Back-End Application With .NET_Xây dựng ứng dụng back-end với .NET

## 1. Thông tin chung
- **Mã môn học (Subject Code):** PRN232
- **Tên tiếng Anh:** Building Cross-Platform Back-End Application With .NET
- **Số tín chỉ (NoCredit):** 3
- **Môn tiên quyết (Pre-Requisite):** [[PRN22x]]
- **Phương pháp dạy:** Social Constructivism,In-class lecture,Inquiry-based Teaching

## 2. Mô tả môn học (Description)
1. Upon completion of this course students shoud:
2. Understand the followings:
• Apply C# language for develop ASP.NET WEB API ( RESTful Service applications )
• Fundamental concepts of .NET Core Platform
• Basic knowledge of ASP.NET WEB API on .NET Core
• Basic knowledge of RESTful Service and Microservice architecture
3. Be able to:
• Develop Cross - platform Back-end application can be used by Desktop or Web applications (Cross - platform)
• Develop RESTful Service applications by ASP.NET Web API and Windows Communication Foundation (WCF)
• Implement security in the ASP.NET WEB API
• Implement sending Ajax request to ASP.NET WEB API
• Implement security JWT in ASP.NET Core Web API
• Develop Distributed applications based on Microservice architecture
4. Be able to work in team and present group's results

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Describe about .NET Core Platform, and ASP.NET WEB API Architecture
- **CLO2:** Demonstrate Models, ODATA, Entity Framework Core ,and Media Formatters & Content Negotiation
- **CLO3:** Demonstrate about implementing security in RESTful WebService
- **CLO4:** Demonstrate about JavaScript Client and sending AJAX Requests to ASP.NET Web API
- **CLO5:** Demonstrate about implementing RESTful Services by WCF, gRPC Services and introduction about Microservices architecture.
