## 2. Mô tả môn học (Description)
1. This course provides students with a solid and comprehensive foundation in digital circuit design. It begins with essential concepts such as number systems, logic gates, Boolean algebra, and logic function simplification. Students then advance to designing and implementing combinational and sequential logic circuits, including multiplexers, arithmetic circuits, flip-flops, shift registers, counters, and memory elements.
2. The course also introduces hardware description languages (VHDL/Verilog), FPGA-based implementation, and fundamental principles of digital signal and data processing. Through these topics, students learn how hardware is described at the Register-Transfer Level (RTL) and how it is verified using testbenches and simulation.
3. In addition, the course provides an overview of the Digital IC Design Flow, including:
4. - Specification and Functional Requirements
5. - RTL Design using HDL
6. - Functional Verification and Testbench Development
7. - Logic Synthesis to Gate-Level Netlist
8. - Timing Analysis and Optimization
9. - Implementation on FPGA or placement & routing (for ASIC)
10. - Post-synthesis simulation and sign-off checks
11. The module emphasizes not only technical competence but also professional ethics, social responsibility, and the development of creativity and problem-solving skills. Students apply theoretical knowledge through laboratory exercises, hands-on projects, and real-world design practices.

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Explain number systems, conversions, codes, and binary arithmetic.
- **CLO2:** Apply Boolean algebra and minimization to design logic circuits.
- **CLO3:** Design and analyze combinational logic circuits.
- **CLO4:** Model and verify logic circuits using HDL.
- **CLO5:** Analyze and design sequential circuits using FSMs.
- **CLO6:** Design and implement registers and counters.
- **CLO7:** Describe memory and PLDs including FPGA resources.
- **CLO8:** Apply RTL design and HDL coding for digital systems.
