# Software Testing_Kiểm thử phần mềm

## 2. Mô tả môn học (Description)
1. • General principles of software testing, including its purposes and objectives.
2. • Testing integrated into software development processes, covering test levels, test types, and maintenance testing.
3. • Static testing basics, including feedback and review processes to enhance software quality.
4. • Techniques such as black-box (functional), white-box (structural), and experience-based testing applied to derive test cases.
5. • Test activities like planning, estimation, monitoring, risk management, defect reporting, and test automation usage.
6. • Tools and methods to support effective testing, emphasizing benefits and potential risks.
7. • AI is used to explore testing concepts, support static testing, and create/optimize Test Plans.

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Know definitions, concepts and terminologies about Software Testing, using AI to explore testing principles and real-world testing scenarios through effective prompts.
- **CLO2:** Understand the software testing process. Distinguish between levels of testing (e.g. unit, integration, system, acceptance) and types of testing (e.g. functional, non-functional) applied to a specific group project (encouraged to choose project in SWP391)
- **CLO3:** Use static testing techniques to detect errors through a review process, using AI to review documents for defects (e.g., ambiguity, inconsistency) and analyze static code for errors (e.g., code smells, bug patterns).
- **CLO4:** Use dynamic testing techniques like black-box, white-box, and experience-based testing to design and execute test cases, and determine test coverage.
- **CLO5:** Develop a comprehensive test plan for an AI-enabled project, clearly defining its scope, goals, resources, and testing schedule.
- **CLO6:** Analyze and prioritize risks to focus testing efforts effectively. Understand and apply bug logging, bug reporting, and test reporting practices.
- **CLO7:** Classify and select appropriate testing tools, evaluate the benefits and risks of test automation, and choose an automation tool for testing functionalities in the team project.
- **CLO8:** Understand and apply Agile testing methods.
- **CLO9:** Utilize AI tools to support learning and exercises related to the course.
- **CLO10:** Demonstrate presentation skills and effective teamwork
