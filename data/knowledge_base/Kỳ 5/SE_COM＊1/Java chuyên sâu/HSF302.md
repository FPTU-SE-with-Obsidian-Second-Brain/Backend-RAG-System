# Working with Spring Framework_Làm việc với Spring Framework

## 1. Thông tin chung
- **Mã môn học (Subject Code):** HSF302
- **Tên tiếng Anh:** Working with Spring Framework
- **Số tín chỉ (NoCredit):** 3
- **Môn tiên quyết (Pre-Requisite):** [[PRJ301]]
- **Phương pháp dạy:** Project based learning,Problem based learning,Active learning,In-class lecture

## 2. Mô tả môn học (Description)
1. Upon completion of this course students shoud:
2. Understand the followings:
• Basic concepts of Java FX to build Desktop Application
• Basics of Object-Relational Mapping (ORM) with JPA and how it simplifies database interactions.
• Spring Framework, Spring Boot, which provides a comprehensive ecosystem for building enterprise-level applications.
• Spring Framework's dependency injection, and web frameworks to build robust and scalable applications
3. Be able to:
• Use JPA ORM tool to map Java objects to database tables.
• Use Spring Framework's dependency injection, and web frameworks to build robust and scalable applications.
• Develop Cross-platform Desktop applications and support for user experience (UI & UX)
4. Be able to work in team and present group's results

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Describe the basics of Object-Relational Mapping (ORM) and how it simplifies database interactions.
- **CLO2:** Describe the concepts of Spring Framework and Spring Boot
- **CLO3:** Describe how Spring Data working with various data sources
- **CLO4:** Undersatnd Spring MVC provides a comprehensive programming and configuration model for modern Java-based enterprise applications.
- **CLO5:** Create Cross-Platform applications using JavaFX. JavaFX is platform-independent, which means that JavaFX applications (CRUD) can run on different operating systems such as Windows, macOS, and Linux
- **CLO6:** Develop teamwork skills, communication skills (including presentation skills)
