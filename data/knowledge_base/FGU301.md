# Fundamental Game Development_Phát triển game cơ bản

## 1. Thông tin chung
- **Mã môn học (Subject Code):** FGU301
- **Tên tiếng Anh:** Fundamental Game Development
- **Số tín chỉ (NoCredit):** 3
- **Môn tiên quyết (Pre-Requisite):** [[PRO192]]
- **Phương pháp dạy:** Social Constructivism,In-class lecture,Inquiry-based Teaching

## 2. Mô tả môn học (Description)
1. This comprehensive Basic Unity Training Program is designed to equip participants with essential skills in Unity game development, empowering them to create engaging and interactive 2D and 3D games. Building upon strong foundation in C# programming, the course delves into advanced topics such as 3D game development, physics, animations, and user interface design. Through a combination of theoretical lectures, hands-on labs, and collaborative projects, participants will gain practical experience and confidence in using Unity to bring their game ideas to life.
2. Key Learning Outcomes:
3. - Master C# Programming: Gain a deep understanding of C# syntax, data structures, algorithms, and object-oriented programming principles.
4. - Navigate the Unity Environment: Become proficient in using Unity's interface and tools for game development.
5. - Develop 3D Games: Learn the fundamentals of 3D game development, including rendering, lighting, animations, and physics.
6. - Create Engaging Game Worlds: Master the art of designing game objects, animations, and physics components to create immersive and interactive game environments.
7. - Build User-Friendly Interfaces: Design intuitive and visually appealing user interfaces that enhance the player experience.
8. - Develop Games from Start to Finish: Complete hands-on projects, applying your knowledge to create your own small games and interactive applications.
9. - Collaborate Effectively: Work collaboratively with teammates to develop game projects, fostering effective communication and teamwork skills.

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Understand C# Programming Fundamentals: Syntax and Data Types, Control Flow, Functions and Methods, Classes and Objects, Debugging
- **CLO2:** Understand C# data structures (lists, stacks, queues, trees) and algorithms (sorting, searching); Event Handling
- **CLO3:** Understand the Unity interface and basic tools for game development
- **CLO4:** Understand 3D Game Development; Rendering and Lighting; Animations and Physics
- **CLO5:** Create and manipulate game objects, animations, and physics components
- **CLO6:** Design user interfaces and handle user input effectively
- **CLO7:** Develop small games and interactive applications using Unity
- **CLO8:** Collaborate effectively in a team environment for game development projects.
