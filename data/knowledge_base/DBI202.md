## 2. Mô tả môn học (Description)
1. - Knowledge about database systems has become an essential part of an education in computer science because database management has evolved from a specialized computer application to a central component of a modern computing environment.
2. - The content of this course includes aspects of database management basic concepts, database design, database languages, and database-system implementation. Basing on these contents, the course emphasizes on how to organize, maintain and retrieve efficiently data and information from a DBMS.

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Understand thedatabase concepts and database management system software
- **CLO2:** Understand the relation model of data and Algebraic Query Language
- **CLO3:** Understand data normalization and apply normalization techniques in database design
- **CLO4:** Be able to model an application’s data requirements using conceptual modeling tools like ER diagrams and design database schemas based on the conceptual model.
- **CLO5:** Be proficient in structure query language including Data Definition Language(DDL) and Data Manipulation Language(DML)
- **CLO6:** Understand PL/SQL concepts and manipulate with View, Cursors, Stored Procedures, Functions, Database Triggers
- **CLO7:** Apply the Index in database design and query optimization
