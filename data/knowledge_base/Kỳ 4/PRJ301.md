## 2. Mô tả môn học (Description)
1. By the end of this course Students will be able to:
2. a) Knowledge: (what will students know?)
3. • Understand the core technologies of Java web programming:
4. - Servlet and JSP
5. - Scope of sharing state (session, application, request,page)
6. • Know how to develop and deploy your own websites using Java
7. • Understand and be able to apply MVC architecture for the web
8. - Learning how to apply JPA in websites using Java
9. • Learning how to apply AI in your own website using Java

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** understand the basic web application structure and be able to deploy Web application
- **CLO2:** understand and be able to work with the basic features of Java web application
- **CLO3:** be able to work with JDBC
- **CLO4:** be able to use different languages in JSP
- **CLO5:** understand and be able to work with other server side objects in Java Web Application
- **CLO6:** understand and be able to work with simple MVC Architecture
- **CLO7:** be able to combine web front-end & back-end in the Java web application.
- **CLO8:** be able to use JPA in the Java web application.
- **CLO9:** be able to use AI in the Java web application.
