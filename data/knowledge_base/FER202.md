# Front-End web development with React_Phát triển web Front-End với React

## 1. Thông tin chung
- **Mã môn học (Subject Code):** FER202
- **Tên tiếng Anh:** Front-End web development with React
- **Số tín chỉ (NoCredit):** 3
- **Môn tiên quyết (Pre-Requisite):** [[WED201c]]
- **Phương pháp dạy:** Project based learning, Problem based learning, Active learning, In-class lecture

## 2. Mô tả môn học (Description)
1. Learn front-end web development for implementing a multi-platform solution:
2. - Overview of client-side web UI frameworks, focusing on Bootstrap. Students will explore grids, responsive design, Bootstrap CSS, and JavaScript components.
3. - Basics of Node.js, npm
4. - JavaScript-based front-end development with the React library: ES6 for React applications, Reactstrap for Bootstrap-based responsive UI, React components, React Router for single-page applications, and designing controlled forms.
5. - Hooks to leverage React features like state and lifecycle in functional components, reducing reliance on class components.
6. - Flux architecture and Redux, covering Redux principles and building React-Redux powered applications.
7. Fetch for client-server communication, integrating REST APIs on the server side.
8. - Modern syntax and patterns for ReactJS development, paired with foundational knowledge to ensure long-term relevance.
9. - AI Integration: Use of AI tools (e.g., code generation with GenAI) to enhance development efficiency, with emphasis on transparency and ethical usage.
10. - Assessment Methods: Evaluation through practical labs, assignments, and reviews using stratified sampling, scored via Likert scales (1-5) for syntax, logic, customization, and transparency, converted to a 10-point scale.
