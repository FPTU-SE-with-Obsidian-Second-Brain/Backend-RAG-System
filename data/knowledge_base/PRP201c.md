- **Số tín chỉ (NoCredit):** 3

## 2. Mô tả môn học (Description)
1. This course will introduce fundamental programming concepts including data structures, networked application program interfaces, and databases, using the Python programming language. In the Capstone Project, students’ll use the technologies learned throughout the course to design and create your own applications for data retrieval, processing, and visualization.

## 5. Chuẩn đầu ra (Course Learning Outcomes)
- **CLO1:** Explain the basics of programming computers using Python
- **CLO2:** Understand fundamental programming concepts such as data structures
- **CLO3:** Create your own applications for data retrieval and processing
- **CLO4:** Describe the basics of the Structured Query Language (SQL) and database design
